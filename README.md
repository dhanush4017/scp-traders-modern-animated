# SCP TRADERS — Modern Animated Single Page Website

A modern single-page static website built with **React**, **Vite**, and **Lucide Icons** for **SCP TRADERS**.

### Key Features
- **Brand Colors**: Royal Blue (`#07489f`), Deep Navy (`#09264a`), Golden Amber/Orange (`#f4a62a`).
- **OnGoMart Inspiration**: Sliding announcement marquee, interactive category cards, responsive product grid with filter pills.
- **Sri Amman Polymers Inspiration**: Food-grade PET container specs (neck finish, sizes 50ml to 20L, leakproof guarantee).
- **Direct WhatsApp Orders**: Instant enquiry buttons pre-filled with product name and capacity.
- **Interactive RFQ Quote Calculator**: Direct wholesale enquiry form.
- **Pulsing WhatsApp Button**: Sticky bottom-right floating pill.

### How to Run
```bash
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.
